# Code of Conduct

## Our standard

Be respectful, constructive, and focused on improving the project. Disagreement about implementation, formatting conventions, or compatibility is welcome; harassment, personal attacks, discriminatory language, threats, and deliberate disruption are not.

## Project spaces

This applies to issues, pull requests, discussions, code review, release coordination, and other spaces used to represent this project.

## Reporting

If conduct in a public thread is inappropriate, avoid escalating it in the thread. Report it to the repository owner through an appropriate private GitHub channel when available. Security vulnerabilities should follow `SECURITY.md` instead.

## Enforcement

Maintainers may edit or remove abusive content, close or lock discussions, reject contributions, or restrict participation when necessary to keep project spaces safe and productive.
